# 🔥 はち - 自動化の鬼 Portfolio

Python・Google Apps Script・スクレイピングで面倒な作業を自動化する専門家のポートフォリオサイトです。

## 🛠️ 主なプロジェクト

- **セラピスト通知 for LINE** - LINE APIを使った出勤通知システム
- **Yahoo!トラベル価格追跡** - GASによるホテル価格監視ツール
- **楽天Room自動投稿** - AI連携の自動投稿システム
- **Webスクレイピング代行** - 各種サイトからのデータ収集
- **EC出品自動化** - メルカリ、ヤフオク等への自動出品

## 💪 技術スタック

- Python (Playwright, Selenium, BeautifulSoup, FastAPI)
- Google Apps Script
- LINE API / Discord API / Telegram API
- Web Scraping & Browser Automation
